# Backend Learning

A personal repository dedicated to learning and mastering backend engineering and DevOps through structured notes, hands-on practice, experimentation, and real-world concepts.

---

## 📚 About

This repository documents my journey toward becoming a strong **Backend + DevOps Engineer**.

The goal is not just to learn frameworks or tools, but to deeply understand:
- how backend systems work,
- how scalable applications are designed,
- and how modern infrastructure is built and maintained.

This repository serves as a long-term knowledge base containing:
- notes,
- code examples,
- experiments,
- mini-projects,
- troubleshooting guides,
- and architectural concepts.

- Build strong backend engineering fundamentals

## 🧠 Learning Philosophy

This repository follows a:

**Learn → Implement → Break → Fix → Document**

approach.

The focus is on:
- learning deeply instead of memorizing,
- understanding the reasoning behind technologies,
- and building practical intuition through experimentation.

Rather than only consuming tutorials, the aim is to:
- build things,
- debug real problems,
- understand internals,
- and continuously improve engineering thinking.
