# JDK

## 💡 TL;DR
- JDK: Java Development Kit.
- It is used by the DEVELOPER.
- It contains:
	- compiler (javac)
	- JRE
	- JVM
	- Debugger
	- Javadoc
	- JAR tool
	- Other development tools
