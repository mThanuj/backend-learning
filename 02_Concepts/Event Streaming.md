# Event Streaming

## 💡 TL;DR
- It is the practice of capturing data in real-time from event sources like databases, sensors, mobile devices and other software applications.
- This ensures continous flow of data so there is no delay.
- Terminologies:
	- **PUBLISH**: Write streams of events.
	- **SUBSCRIBE TO**: Read streams of events.
	- **STORE**: Store streams of events efficiently.
	- **PROCESS**: Process streams of events as they occur.
