# Kafka Servers

## 💡 TL;DR
- Kafka is usually a cluster of one or more servers that can span multiple datacenters or cloud regions.
- Some servers might run a storage layer called brokers, and some servers run kafka connect to continously import and export data as event streams to integrate kafka into exist
