# Inheritance

## 💡 TL;DR
- One class acquires properties of another.

## 🛠️ Syntax / Code Example
```java
class Animal {

    void eat(){}

}

class Dog extends Animal { }

// now we can use eat() via Dog object
Dog dog = new Dog();
dog.eat();
```
