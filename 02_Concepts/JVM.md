# JVM

## 💡 TL;DR
- JVM: Java Virtual Machine.
- The responsibilities include:
	- Loading classes
	- Verifying bytecode
	- Managing Memory
	- Running the Garbage Collector
	- Executing bytecode
	- Converting bytecode to machine-code using interpreter and JIT compilation
- Its like an operating system for Java Programs.
