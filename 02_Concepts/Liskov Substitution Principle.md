# Liskov Substitution Principle

## 💡 TL;DR
- Child classes should not violate the behavior expected from the parent.
- A child class should be replaceable by its parent without breaking the program.
- For example:
	- If I have a parent class 'Bird' (it has a method 'fly') and child class 'Sparrow', it works for now.
