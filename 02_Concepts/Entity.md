# Entity

## 💡 TL;DR
- An entity is the java representation of a table in a database.
- This is basically a class with properties representing the columns in a table.
- Annotations used commonly in entity are:
	- @Id: Primary Key of a table. This is required for an entity.
	- @Column: All the properties of a column and their constraints.
