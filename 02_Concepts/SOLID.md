# SOLID

## 💡 TL;DR
- It is a set of 5 design principles that make code:
	- Easier to maintain
	- Easier to test
	- Easier to extend
	- Less coupled
- They are:
	- Single Responsibility Principle
	- Open/Closed Principle
	- Liskov Substitution Principle
